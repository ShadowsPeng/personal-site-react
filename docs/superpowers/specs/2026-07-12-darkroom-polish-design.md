# 暗房精修版前台视觉优化设计

## 目标

在不改变现有内容结构和核心交互的前提下，提升个人站的视觉完成度、信息可读性和移动端体验。整体继续使用暗色摄影、暖金点缀、胶片与舞台感，但减少装饰元素之间的竞争，让作品、个人信息和音乐互动成为页面主角。

## 范围

- 调整 `src/index.css` 的全局设计令牌、布局间距、组件状态和响应式规则。
- 仅在确有必要时微调 `Nav`、`Hero`、`About`、`Photos`、`Footer` 的 class 结构或可访问性属性。
- 保留 `Music` 的播放、拖拽、独奏、预设场景等现有行为。
- 保留 dark / light / mono 三套主题，并保证新增样式通过现有 CSS 变量适配。
- 不新增第三方依赖，不更换图片、音频和视频资源。

## 视觉方案

### 全局

- 以更深的背景层次和低对比边框建立内容分区。
- 统一卡片圆角、控件高度、焦点态和 hover 反馈。
- 通过 `clamp()` 和统一容器宽度控制桌面与移动端的节奏。
- 让文字颜色分成主标题、正文、辅助信息三级，避免辅助文字过亮。
- 装饰性动画继续保留，但支持 `prefers-reduced-motion`，并降低扫描线、网格和光晕的不透明度。

### 导航

- 桌面端使用轻量玻璃背景与细边框，滚动后提升背景不透明度。
- 提高当前导航和主题按钮的可辨识度，补充键盘 focus-visible 样式。
- 移动端压缩内边距与链接间距，避免导航与首屏内容挤压。

### Hero

- 保留全屏图片/视频和暖金标题，但将标题最大尺寸从“铺满首屏”调整为更稳定的响应式比例。
- 通过左侧渐变和底部渐变增强正文、角标和滚动提示的可读性。
- 将首屏信息分为身份 eyebrow、姓名、英文/中文副标题、简介和次级信息，保持清晰的阅读顺序。
- 轮播点、滚动提示和角落信息统一层级，避免多个元素争夺视觉中心。

### About / Photos / Footer

- About 使用更明确的两栏关系：文字与身份信息为主，肖像卡片作为视觉锚点。
- 统计项和标签采用统一的细边框组件语言，减少不必要的重背景。
- Photos 强化封面标题、分类标签和图片 hover 的轻微位移/遮罩反馈。
- Footer 增加内容分组之间的间距和移动端折行规则，让联系方式成为明确的收束点。

### Music

- 不改功能，仅统一播放列表、运输控制条、舞台和快捷场景按钮的间距与状态色。
- 保留舞台的暖金氛围，但弱化装饰网格和过强光效，以突出乐手互动。
- 移动端将侧栏改为顶部横向可滚动列表，避免主舞台被压缩得过小。

## 响应式与无障碍

- 以 768px 为主要移动端断点，并为窄屏增加必要的字体和间距收缩。
- 所有可点击控件保留清晰 hover、focus-visible 和 disabled 状态。
- 图片继续使用合适的 `alt`，装饰性元素不参与阅读顺序。
- `prefers-reduced-motion: reduce` 下关闭或大幅减少轮播、扫描线、网格和 hover 位移动效。

## 验证标准

- `npm run lint` 通过。
- `npm run build` 通过。
- 桌面宽度下首屏标题、导航和角落信息不重叠。
- 375px 左右窄屏下导航、Hero、音乐区、照片区和 Footer 无横向溢出。
- 三套主题均可正常切换，主题切换后文字与边框仍保持足够对比度。
- 音乐播放、列表切换、主题切换和照片浏览行为不回归。
